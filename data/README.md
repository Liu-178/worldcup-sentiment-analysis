## 数据文件说明

### 原始数据（爬虫采集）
- raw_2022_qatar.csv - 2022卡塔尔世界杯新闻原始数据
- raw_2026_usmx.csv  - 2026美加墨世界杯新闻原始数据

### 清洗后数据
- cleaned_2022_qatar.csv - 2022数据清洗结果
- cleaned_2026_usmx.csv  - 2026数据清洗结果

### 统计分析结果
- industry_stats.csv     - 行业热度统计
- timeline_stats.csv     - 时间序列统计
- word_freq_2022.csv     - 2022词频统计
- word_freq_2026.csv     - 2026词频统计

## 数据字段说明

原始数据CSV字段：
| 字段名 | 说明 |
|:------:|:----:|
| title | 新闻标题 |
| publish_time | 发布时间 |
| source | 新闻来源 |
| summary | 内容摘要 |
| industry | 所属行业 |
| keyword | 匹配关键词 |
